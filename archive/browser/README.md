# Retired browser game

Historical source only. Tatchamashay is the iPhone game in `../../ios/`.
The browser game and PartyKit server are unsupported; npm development, build, preview and deployment
commands intentionally fail. Do not deploy this directory or add gameplay, characters, fixes or parity
work here. Git history preserves the original commands if historical investigation is needed.

The models here are historical references, not an approved iPhone content catalog. Before adopting
one, verify provenance and convert, register and test it in the iPhone asset pipeline.

The pre-existing local package-lock changes were preserved during relocation. No dependencies were
installed or updated as part of retirement. The root LICENSE continues to apply.
