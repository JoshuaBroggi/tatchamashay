# Tatchamashay

Tatchamashay 2.0 is an iPhone app. This repo is iPhone-first.

- [`ios/`](ios/) — the iPhone app. Start with [`ios/AGENTS.md`](ios/AGENTS.md).
- [`web/`](web/) — the retired 1.x browser game (React, Three.js, PartyKit), kept for reference. It has its own GPL [`LICENSE`](web/LICENSE) and is no longer maintained; some models were removed, so parts of it no longer load.

The last complete version of the web game can be recovered from the git tag `v1-web-final`:

```bash
git checkout v1-web-final
```
